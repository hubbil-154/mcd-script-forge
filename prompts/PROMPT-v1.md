## 一、产线节拍表（Cue Sheet）

一切画面与声音都从**同一张表**读取，这张表就是产线：

1. **0–0.5s 必须有钩子**：禁止超过 0.3s 的空场或黑场；第一眼要么有冲突、要么有反差、要么有数字。
2. 全片 3–5 个节拍（beat），每个 beat 标注：起止时间码 / 画面动作 / 音效名 / 文案。**60–75% 进度处安排一个英雄时刻**（全片记忆点）。
3. 结尾定格 0.8–1.2s，且画面必须保留微动（呼吸感），不许死帧。
4. 节拍表先于一切代码存在。改节拍必须先改表，再改代码——表和片永远不许失配。
5. 配乐从节拍表直接合成（本仓库 `make_audio.py` 模板：96/120 BPM 起步，kick/shaker/blip/swish 与时间码逐帧对齐），母带两趟 loudnorm。

## 二、分层规格（Output Spec）

- 1080×1920（或项目指定），30fps，精确到毫秒的时长（帧数=秒数×30），H.264 MP4 + AAC 48kHz，**I = −14 LUFS，真峰 ≤ −1 dBTP**。
- **确定性渲染**：每一帧都是时间 t 的纯函数。随机数必须带种子；物理与粒子预计算或闭式解；禁止实时时钟、禁止状态触发的 CSS 过渡。
- 可靠管线：网页暴露 `renderAt(t)` → 无头浏览器逐帧抓取 → ffmpeg 编码（**显式 `-framerate 30`**）→ 音轨两趟 loudnorm 后 `-c:v copy` 灌轨。
- 快速运动用超采样（累积器法：第 i 帧 α=1/(i+1)，总权重恒为 1）。
- 字体子集化后嵌入；屏上文字必须准确地道、CJK 标点规范、无豆腐块。
- 素材白名单：CC0 / OFL / Apache / 可商用授权，逐条记录在 CREDITS.md；**禁止真实品牌商标，品牌一律自造**。

## 三、风格契约（Style Contract）★二选一，全片一字不改地执行

### A. 新粗犷主义 Neo-Brutalism

- **一眼识别**：粗黑描边（4–8px）、**硬偏移阴影**（实心色块偏移 8–12px，绝不用模糊）、块状贴纸式排版、故意的"笨拙感"。
- 色板（5–6 色，敢撞）：奶油底 `#F5F1E8`、墨黑 `#141414`、警示红 `#FF4D2E`、信号黄 `#FFD100`、电光蓝 `#3D7BFF`、酸绿 `#B8F135`。品牌色替换时保持"至少两对高冲撞组合"。
- 字体：超粗无衬线，字号对比拉到极端（同一画面允许 900 重 96px 撞 700 重 28px）。
- 动效性格：**砸**——元素带冲击入场，落位瞬间画面抖动 2–3 帧；缓动允许大过冲；硬切优先于叠化。
- 禁忌：渐变、软阴影、圆角>16px、细腻质感、优雅的留白节奏。它要"生"，不要"美"。

### B. 瑞士国际主义 Swiss International

- **一眼识别**：严格网格（6/12 栏，栏缝可见）、超大字号无衬线、大量**结构性留白**、红黑灰三色统治、文字本身当图形用。
- 色板（克制）：纸白 `#F2F0EB`、印刷黑 `#111111`、瑞士红 `#E30613`、至多一个辅助色（蓝 `#1D4ED8` 或品牌色）。**灰阶层次靠字重与字号，不靠颜色数量**。
- 版式：非对称平衡——大标题压一角，信息沿网格阶梯排布；辅助线、标尺刻度、页码这类"印刷结构元素"可以入画当装饰。
- 动效性格：**准**——无过冲、无弹跳；缓动用标准 ease-in-out；元素沿网格线滑动到位、停准；节奏感来自"揭示"（遮罩拉开、逐行浮现、线条画入），不来自晃动。
- 禁忌：斜向投掷、果冻感、装饰性图形、超过三种颜色、居中对称的懒人版式。

### 共同铁律
扁平即扁平：**零渐变**（契约明确允许的除外）；高光用纯色块；每个几何体两阶明暗（亮面/暗面各一色）。

## 四、运镜法则（Motion Laws)

1. **一镜到底优先**：站与站、段与段之间用元素驱动转场（一个物体飞出并"带走"整个画面），禁止无意义叠化。
2. 同一时刻只有一个主体在动，其余元素保持或微动；元素错峰入场 2–4 帧，每个带自己的小过冲。
3. 预备→冲出→落定三段式；位移带 ~10% 挤压拉伸（瑞士契约可减半，换取"稳"）。
4. 每个动画属性必须有唯一数据源（关键帧表/节拍表），**禁止两处代码各自推算同一属性**。
5. **四表自检**每帧登记：REG（元素边界）/ BLEED（出血）/ SCREG（字幕安全区）/ MREG（页眉禁区），自动扫描 150+ 采样点，越界数为零才算过。
6. 层级有争议的元素（插入、遮挡、穿层），写代码前先用一句话写下层级顺序，画完用**像素探针分区域数目标色**验证（前景色在"应被遮挡区"必须为 0）。

## 五、验收关卡（Exit Gates）

逐关通过才算完工，任何一关失败回到对应产线段返工：

1. **规格关**：时长/帧数/分辨率/响度/真峰，ffprobe 实测数字写进报告。
2. **动检关**：全片逐帧差分，无意图的死区（连续 ≥5 帧变化 <0.02）为零。
3. **静帧关**：6–10 个关键时间点渲染静帧，每帧海报级——构图、层级、负空间、字距行高；像素级色块核验（各区域主色占比达标）。
4. **层级关**：所有穿插/遮挡关系的分区域像素断言全 PASS。
5. **成品关**：对最终 mp4 本体（不是中间产物）抽帧复检第 3/4 关。
6. **合规关**：无真实商标、无未授权素材、文字零错别字。
7. **诚实自评**：风格还原 / 创意 / 动效 / 排版 / 完成度 / 声音 6 项各打 1–10（6=模板级，8=代理级，9=入围级），最低项先修。
8. **交付**：video.mp4 + 报告（两句话概念、节拍表、契约落实对照表、实测数字、前三弱项）。
